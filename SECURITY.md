# Security

Do not include secrets, camera images, RTSP URLs with credentials, device identifiers or Home Assistant storage files in public issues. Diagnostics deliberately return only model, firmware, availability and control keys.

For a vulnerability, use GitHub's private vulnerability reporting if enabled. Public discussions should contain only a minimal synthetic reproduction. This is a local-network integration, not an Internet-facing camera proxy. Keep the camera and HA on trusted networks and update them through their supported maintenance paths.
